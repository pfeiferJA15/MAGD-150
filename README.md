# MAGD-150

### **pfeiferJLab7**

This work was made for _Lab Assignment 7_, which revolved around using array manipulation methods, array info methods, and text().
In my code, I created a list of fruits. From there, a random assortment of half would be "eaten" and moved into a different array.
From there, a random fruit was drawn from both the arrays of eaten and uneaten fruits, as well as a third combined array.

### **pfeiferJLab8v2**

This work was made for _Lab Assignment 8_, which had us use Simple Web Server to use images and preload() in p5.js.
In my code, I preloaded images of UWW campus as well as a Christmas tree in order to make a greeting card.
The Christmas tree's position tracks both mouseX and mouseY.

### **pfeiferJLab10**

This work was made for _Lab Assignment 10_, which had us test out an additional p5.js library of our choice to make a proof of concept for the final project.
I chose to use the library p5.fps.js, which adds a built in active fps counter to be displayed on the canvas.
My code uses a moving red ball to demonstrate how fps affects animation speed, with key inputs making the fps go up or down.
I intend to expand this idea for my final project, making a small game where the player must set the game to a randomized target fps before the ball goes past a certain threshold.
